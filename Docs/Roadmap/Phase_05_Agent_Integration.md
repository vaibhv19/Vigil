---

## 2. Purpose
This phase establishes the boundary between the evaluation system and the agent under test. By designing a pluggable adapter abstraction, we ensure the core evaluation harness remains decoupled from agent internals. We then implement a concrete adapter for **LangGraph** (the first supported agent integration) to receive prompt inputs, register virtual tools that redirect execution to the sandbox, run its reasoning loop, and return the agent's final text outcome.

---

## 3. Dependencies
### 3.1 Internal Modules
- `vigil.core.tool_models` (To execute commands through the container routing layer)
- `vigil.core.tool_executor` (To intercept tool requests and return results to the agent)

### 3.2 External Libraries
- **langgraph**: `^0.0.10` (State graph execution engine)
- **langchain-core**: (For tool and message definitions used by LangGraph)
- **pydantic**: (For tool input parsing and validation)

---

## 4. Inputs
- Input prompt string (from the task definition).
- References to the active `ToolExecutor` representing the running sandbox session.
- Agent environment configuration (API keys, model parameters).

---

## 5. Outputs
- Final text response generated by the agent reasoning loop.
- Side-effects executed inside the sandbox (via virtual tool requests routed to the container).
- Exceptions such as `AgentExecutionError` if the agent crashes or exceeds step limits.

## 6. Public Interfaces
### 6.1 Base Agent Adapter (`vigil/agents/base_adapter.py`)
```python
from abc import ABC, abstractmethod
from typing import Any
from vigil.core.tool_executor import ToolExecutor

class BaseAgentAdapter(ABC):
    @abstractmethod
    def run_task(self, prompt: str, tool_executor: ToolExecutor) -> str:
        """
        Executes the agent reasoning loop against the prompt, registering
        available tools that route command execution to the tool_executor.
        Returns the agent's final text response.
        """
        pass
```

### 6.2 LangGraph Adapter (`vigil/agents/langgraph_adapter.py`)
```python
class LangGraphAgentAdapter(BaseAgentAdapter):
    def __init__(self, model_provider: str = "openai", model_name: str = "gpt-4o-mini", **kwargs: Any):
        self.model_provider = model_provider
        self.model_name = model_name
        self.config = kwargs

    def run_task(self, prompt: str, tool_executor: ToolExecutor) -> str: ...
```

## 7. Internal Components
- **`VigilSandboxTool`**: A LangChain-compatible `@tool` declaration that intercepts tool calls from the agent, wraps them in a `ToolRequest` DTO, passes it to the `ToolExecutor`, and returns the stdout result.
- **`LangGraphState`**: LangGraph State schema tracking chat history and internal state variables.
- **`ReActLoopBuilder`**: Constructs the state graph compile nodes (`should_continue`, `call_tool`, `agent`).

## 10. Definition of Done (DoD)
- The pluggable `BaseAgentAdapter` interface decouples the harness from specific framework details.
- LangGraph adapter compiles ReAct graphs successfully.
- Virtual sandbox tool correctly intercept commands, passing execution payloads to the Docker SDK wrapper.
- Adapter supports limiting steps to prevent runaway loops.
- Integration tests verify agent execution workflows using mocks.
